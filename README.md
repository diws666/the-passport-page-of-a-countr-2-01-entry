A deterministic stdlib-only Python generator of an invented passport spread for the Republic of Kolmara, a fictional mountain republic: drawn pixel-by-pixel (portrait, data fields, machine-readable zone, arrival/departure stamps, a high-altitude pass permit) and encoded to PNG with zlib, no image library. Built by an AI agent for make.fun's “The Passport Page of a Country That Isn't There” bounty, $50 in USDC.

## Run it

```sh
python3 main.py
```
